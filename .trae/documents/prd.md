## 1. 产品概述

香囊手作活动配料清单与分组管理工具，面向手作活动组织者在活动开场前快速核对布袋、填充物、绳结等物料及小组任务准备情况。纯前端应用，数据本地保存，开箱即用。

- 解决问题：活动前物料核对繁琐、分组任务分散、异常情况难以及时发现
- 目标用户：手作活动组织者、工坊老师、团建策划者
- 核心价值：一站式管理材料包状态，自动发现异常，按小组输出执行清单

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 组织者 | 无需注册，本地使用 | 全部功能，数据本地存储 |

### 2.2 功能模块

1. **配料清单主页**：材料包列表展示、多条件筛选、批量操作、异常提醒
2. **新增/编辑弹窗**：完整的材料包信息录入
3. **自动检查面板**：实时检测各类异常情况
4. **分组执行清单**：按小组维度展示待办与提醒

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|----------|----------|
| 配料清单主页 | 顶部工具栏 | 标题、新增按钮、视图切换（清单模式/分组模式） |
| 配料清单主页 | 筛选栏 | 按款式、难度、责任人、状态、小组筛选 |
| 配料清单主页 | 批量操作栏 | 全选、批量标记状态（待准备/可分发/需补料/改为演示） |
| 配料清单主页 | 材料包列表 | 卡片式展示材料包信息，支持单行编辑删除 |
| 配料清单主页 | 异常提示条 | 展示自动检查发现的问题数量与快捷定位 |
| 新增/编辑弹窗 | 表单区域 | 香囊款式、材料包编号、适合人数、难度、预计时长、示范要点、缺料说明、责任人、状态、所属小组 |
| 分组执行清单 | 小组卡片 | 按小组展示材料包、数量统计、缺料提醒、准备清单 |

## 3. 核心流程

组织者打开应用 → 查看/筛选材料包清单 → 新增或编辑材料包信息 → 系统自动检查异常 → 批量调整状态 → 切换分组执行清单模式 → 按小组核对准备情况 → 数据自动保存到本地

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：琥珀暖色系（amber-600），搭配米色背景，营造手作温馨感
- 辅助色：翡翠绿表示就绪、珊瑚红表示异常、天空蓝表示进行中
- 字体：标题使用衬线字体增强手作质感，正文使用清晰易读的无衬线字体
- 卡片风格：圆角卡片，柔和阴影，微立体效果
- 按钮风格：圆角按钮，hover 时有轻微上浮和阴影加深
- 图标风格：线性图标，与整体温馨风格统一

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|----------|---------|
| 配料清单主页 | 顶部标题区 | 大标题、副标题说明、新增按钮、视图切换开关 |
| 配料清单主页 | 筛选栏 | 多维度筛选器 | 下拉选择器、标签式筛选 |
| 配料清单主页 | 批量操作栏 | 全选复选框、批量操作按钮组、选中数量提示 |
| 配料清单主页 | 材料包列表 | 卡片网格布局、状态标签、操作按钮 |
| 配料清单主页 | 异常提示 | 红色警示条、问题列表、可折叠 |
| 新增/编辑弹窗 | 弹窗 | 居中弹窗、表单、确定取消按钮 |
| 分组执行清单 | 小组卡片 | 小组标题、统计数据、材料包列表、提醒语 |

### 4.3 响应式

- 桌面端优先设计，支持平板和移动端自适应
- 卡片列表在小屏幕下调整为单列
- 筛选栏在移动端可折叠
- 触摸设备优化按钮尺寸

### 4.4 交互动效

- 页面加载时卡片渐入动画
- 状态切换时的平滑过渡
- 弹窗淡入淡出
- 悬停微交互反馈
